## The entry

One line, 71 characters — the commit message of a developer who just
fixed production at 3 AM:

> fix: reverted my 3 AM deploy. prod is back up. my dignity is still down

## How it works

`main.ts` (pure Node standard library, no dependencies) writes that single
line to `/output/entry.txt`. It never deletes the output directory itself.

Run it locally:

```sh
OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
